# Gabriel Paolini de Miranda

### Engenheiro de Software · Backend, Plataforma e Produtos Digitais

Construo sistemas confiáveis para problemas que exigem integração, segurança e operação contínua.
Atuo com APIs, arquitetura de software, IAM, CI/CD, automações com IA e aplicações web modernas.

- **Backend e arquitetura:** PHP, Laravel, Node.js, TypeScript, Python, REST APIs, integrações e jobs assíncronos.
- **Plataforma e segurança:** Docker, CI/CD, GitLab, Nginx, Keycloak, OAuth2, OpenID Connect, JWT e SSO.
- **Dados e operação:** PostgreSQL, Oracle, Redis, observabilidade, performance e sustentação de sistemas críticos.
- **Frontend:** React, Next.js, TypeScript, Tailwind CSS e design systems.
